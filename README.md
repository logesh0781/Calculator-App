# 🧮 Calculator App

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.

The calculator supports basic arithmetic operations, keyboard input, percentage calculation, and responsive mobile design.

## 📸 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 💯 Percentage calculation
- 🔢 Decimal numbers
- ⌫ Delete last character
- 🧹 Clear display
- 📱 Responsive mobile design
- 💻 Works on desktop and mobile browsers

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The calculator is designed to work on:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop computers

CSS media queries are used to adjust the calculator size, buttons, and display according to the screen size.
